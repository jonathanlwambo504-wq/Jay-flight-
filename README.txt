DAYFLOW clean starter project

This is a fresh native Android starter project.
Features in this first build:
- Native monthly calendar
- Select a date
- Add events
- Delete events
- Save events locally using Android SharedPreferences

Build:
- Open this folder as an Android project in Android Studio, OR
- Push the contents to a GitHub repository connected to Codemagic.
- Codemagic reads codemagic.yaml from the repository root.

Note: This starter currently has calendar/event storage only. Scheduled notifications, editing events,
homework, timetable, artist wallpapers and music reminders are planned next.
